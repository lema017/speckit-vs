# Security Policy

This repository is a fork of [github/spec-kit](https://github.com/github/spec-kit), maintained independently by [lema017](https://github.com/lema017). GitHub does not maintain this fork, so please report security problems in it here, not to GitHub.

## Reporting Security Issues

**Please do not report security vulnerabilities through public GitHub issues or pull requests.**

Instead, please use [private vulnerability reporting](https://github.com/lema017/speckit-vs/security/advisories/new).

Please include as much of the information listed below as you can, to help understand and resolve the issue:

- The type of issue (e.g., buffer overflow, SQL injection, or cross-site scripting)
- Full paths of source file(s) related to the manifestation of the issue
- The location of the affected source code (tag/branch/commit or direct URL)
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit the issue

This information helps triage your report more quickly.

If the vulnerability also affects the original project, please report it there too, as its [security policy](https://github.com/github/spec-kit/blob/main/SECURITY.md) describes.
