# Support

## How to get help

Please search existing [issues](https://github.com/lema017/speckit-vs/issues) before creating new ones to avoid duplicates.

- Review the [README](./README.md) for getting started instructions and troubleshooting tips
- Check the [comprehensive guide](./spec-driven.md) for detailed documentation on the Spec-Driven Development process
- Open a [GitHub issue](https://github.com/lema017/speckit-vs/issues/new) for bug reports and feature requests

## Project Status

This repository is a fork of [github/spec-kit](https://github.com/github/spec-kit), maintained independently by [lema017](https://github.com/lema017). GitHub does not maintain or support this fork, so please report problems with it here, not in the original project. We will do our best to respond to support and feature requests as time permits.

## Support Policy

Support for this project is limited to the resources listed above.
